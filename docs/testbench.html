Does the alarm make the fly jump?

A simulation always prints numbers. The hard part is knowing whether they're right. This page shows how we decide: what we expected before running, what we got, and the raw evidence to look at yourself.

0 · how do we know it's right?

Decide what "right" means before you run anything

Every check below was written as a prediction first. "Right" comes from four places. If you know software testing, you already know all four.

PublishedAnother lab measured it. We must get the same number. like a known expected output
ControlThe answer is known by construction: no input, or a cell switched off, must give zero. like a negative test
ScrambledRewire the brain at random. The result must break, or the wiring isn't doing the work. like removing the feature
ConsistentTwo ways of computing the same thing must agree. like a regression test

1 · what's being tested

One circuit, five kinds of test

In the fly's map, two kinds of alarm cells are the jump cell's biggest inputs. We switch them on at different strengths, from 0 to 200 times per second, and ask the jump cell two questions: do you fire? and how fast?

  1. 1Real wiring, both alarm types. The main test.
  2. 2Only LPLC2. How much does each alarm type do on its own?
  3. 3Only LC4. The other alarm type on its own.
  4. 4Jump cell switched off. control It should never fire. Checks our off switch works.
  5. 5Scrambled wiring, 5 versions. control Same cells, same number of connections, random partners. If these still jump, the fly's wiring isn't what's doing it.

Each test runs 400 ms of fly time: 50 ms quiet, 300 ms of alarm, 50 ms quiet. Each one was repeated 10 times with different random timing.

Synapse counts are for the right-side jump cell in the FlyWire map: LPLC2 is its biggest input type, LC4 the second biggest. About half of all its inputs are inhibitory, the brakes, so firing is not guaranteed.

5 · in plain words

What we learned

The alarm reaches the jump cell.

With the real wiring, the jump cell fired in every single try once the alarm was on, even at the weakest setting.

Stronger alarm, faster reaction.

A strong alarm makes the jump cell fire within about 4 to 6 ms. A faint one takes 20 to 30 ms. One frame of the game is 16.7 ms, so a strong alarm gets a reaction inside a single frame.

LPLC2 matters more than LC4.

Either one alone can trigger the jump cell, but LPLC2 alone works almost as well as both together. LC4 alone needs a stronger alarm. That matches the map: LPLC2 has more synapses onto the jump cell.

Scrambled wiring: no jump.

Across 5 scrambled brains, the jump cell essentially never fired, even though hundreds of other cells were busy. So it's the fly's real wiring that carries the alarm to the jump cell.

The off switch works.

With the jump cell switched off it never fired, so we can use this as the "no jump cell" control in the game.

What this does not show yet.

Here the alarm is simply on or off. In the game, it has to grow as the spike gets closer, and the jump has to land in a window about 45 ms wide. That's the next step. Also, the real jump cell has electrical connections that aren't in this map, so the model may react differently from a living fly.
